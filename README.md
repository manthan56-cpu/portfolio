## 🌟 Overview

This repository houses the personal developer portfolio of **Manthan Rajput**, an engineer specializing in full-stack architecture, high-performance web systems, and creative front-end design.

Rather than adhering to standard minimalist tech layouts or generic dark-mode SaaS grids, this portfolio reimagines personal branding as a **Maximalist Retro-Delhi Carnival & Tactile Papercut Diorama**, incorporating multi-planar parallax, vintage Indian street typography, interactive transistor radios, and physical stacking drawers.

---

## 📸 Key Sections & Interactive Features

### 1. 🎪 Multi-Planar Parallax Stage (`#hero`)
- **Atmospheric Depth**: Delhi midnight skyline layered with floating clouds, sunrise flame overlay, and heritage foliage.
- **Continuous Delhi Metro Animation**: Custom vector metro train traversing the historic rail bridge every 14 seconds.
- **Concentric Vinyl Turntable**: Six hardware-accelerated concentric vinyl discs continuously spinning at 60/120 FPS with zero jitter. Hovering rings trigger instant tactile inversion and golden bloom without disrupting the rotation timeline.

### 2. 📰 "Spilling The Tea" — Selected Work (`#work`)
- **Retro Newspaper Editorial**: Designed as *"All The Riot That's Fit To Print"*, complete with authentic torn paper edges and a steaming hot cutting chai illustration.
- **Interactive Clippings**: 4 angled newspaper article cards that level out, cast deep shadows, and elevate on cursor hover.

### 3. 📜 Engineering Manifesto (`#about`)
- **Cultural Diorama**: Handcrafted retro stamp layout featuring an animated bobbing avatar, stamped seals, and foundational software engineering philosophies.

### 4. 🛺 Delhi Auto-Rickshaw — Tech Stack (`#stack`)
- **Living Vector Machine**: Custom Delhi auto-rickshaw diorama featuring engine idle chassis vibrations and dual-stage headlight glow pulses.
- **Toolkit Grid**: Production competencies grouped across Languages, Frontend Systems, Distributed Backends, and Cloud Infrastructure.

### 5. 🎸 Career Journey & Experience (`#journey`)
- **Quad-Lane Infinite Marquee**: 4 vertical conveyor columns cycling asynchronously up and down.
- **Tactile Interaction**: Hovering over any column seamlessly pauses movement for reading; clicking cards reveals role milestones, metrics, and achievements.

### 6. 📻 Retro Transistor Radio Tuner (`#radio`)
- **Authentic Wooden Radio**: Complete with speaker grille vibration simulations, dual-axis control knobs, and an interactive red frequency needle.
- **Dynamic Band Switcher**: Toggle between *Culturals Mode* (Festival Audio & Vibes) and *Tech Mode* (Developer Podcasts & System Architecture).

### 7. 🎁 Interactive Mystery Box
- **Lottery State Machine**: Vibrating retro mystery parcel with animated question mark that reveals surprise engineering memes and interactive rewards.

### 8. 📟 Retro Terminal Command Center (`#footer`)
- **Live Indian Standard Time (IST) Clock**: Real-time ticker synchronizing local Delhi time.
- **Vintage Command Line Deck**: Terminal status badges, quick navigation anchors, and direct contact channels.

## 🛠️ Technology Stack & Engineering Philosophy

- **Semantic HTML5**: Clean, accessible DOM hierarchy with structured headings, ARIA accessibility attributes, and keyboard-navigable anchors.
- **Modern CSS3 (Zero Third-Party CSS Frameworks)**:
  - 100% custom CSS variables for design tokens, typography, and section-specific atmospheric palettes.
  - Native `position: sticky; top: 0;` curtain stacking architecture.
  - GPU hardware-accelerated transforms (`translate3d`, `will-change: transform`, `backface-visibility: hidden`).
  - 22 bespoke keyframe animations running smoothly on compositor threads.
- **Vanilla JavaScript (ES6+)**:
  - Zero heavy external dependencies (no bulky React or Three.js runtime overhead).
  - Web Audio API integration for radio feedback and turntable interaction.
  - Efficient event delegation and state machines for the mystery box and tuner.

## 🚀 Quick Start & Local Preview

To explore or run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/manthan56-cpu/portfolio.git
cd portfolio

# 2. Run with any local HTTP server
# Using Python:
python3 -m http.server 8000

# Using Node.js (npx serve):
npx serve .

# Using Vite (if installed):
npx vite
```

Open your browser and navigate to `http://localhost:8000/`.
